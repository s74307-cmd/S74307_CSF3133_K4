About the Event

The Faculty Programming Workshop 2026 is a one-day event designed to help students improve their programming skills and learn about software development.

Introduction to Web Development

Students will learn the basics of HTML and how to create their own web pages. This session is suitable for beginners.

Hands-on Coding Challenge

Participants will work on programming exercises and solve problems using logical thinking and coding skills.
